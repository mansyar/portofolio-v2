## Notes

- **Name choice:** the query is `listForAdmin`, not `listSubscribers`, because the harden
  track's regression test asserts that exact export stays absent. Reusing the name would
  mean deleting a security test, so the guard is expressed as a distinct, admin-scoped read.
- **Token exclusion:** the admin page never receives `unsubscribeToken`. A token is an
  authorization secret; putting it in a CMS payload would let anyone with a screenshot opt
  a subscriber out.
- **Test ordering trap:** importing `newsletter.ts` at the top of the test file freezes
  `lib/auth.ts`'s `ADMIN_EMAIL` before the stub applies, which is why the export assertion
  imports the module inside the test instead. The first run failed exactly that way and is
  reflected in the notes rather than hidden.
