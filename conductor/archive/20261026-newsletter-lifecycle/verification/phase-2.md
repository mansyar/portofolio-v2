## First gate run and its cause

The first full gate exited 1 on `pnpm type-check` with
`Argument of type '"/newsletter/unsubscribe"' is not assignable to parameter of type
'keyof FileRoutesByPath'`. The committed route tree is generated: it did not yet know the
new route, so the route id and `Route.useSearch()` were untyped. `pnpm build` regenerated
`src/routeTree.gen.ts` (now containing `NewsletterUnsubscribeRoute`), and the gate was re-run
from scratch with all five commands exiting 0. No source change was needed to fix it.

## Notes

- **Single-shot guard:** the mutation runs from an effect. A `useRef` guard keeps it to one
  call per page load, which the `StrictMode` test pins.
- **No token echo:** the page never renders the token, so it cannot be copied out of the
  DOM after use.
- **Fallback for unbackfilled rows:** a subscriber without a token gets mail with no footer
  link rather than a broken one. That is temporary and disappears once
  `normalizeSubscribers` runs.
- **Test isolation:** `SITE_URL` is stubbed per test and restored afterwards; no test reads
  real configuration.
