## Summary

Removes the TanStack starter's seven `/demo` routes and the demo-only data module from the
shipped application, including the generated route-tree entries that registered them and an
unauthenticated POST server function that wrote `todos.json` in a read-only container. It
also makes the admin dashboard honest: "View All" and "Draft New Post" now link to routes
that already existed, the fabricated System Status panel is gone, and `docs/PROGRESS.md`
agrees with itself about Phase 9.
