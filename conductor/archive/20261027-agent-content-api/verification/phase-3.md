## Notes

- **Why the write path skips `requireAdmin`.** `create` is an `internalMutation`,
  reachable only from the HTTP action, which verifies the bearer token before it
  calls in. There is no session to check because there is no session; the
  reachability argument is what replaces the admin check, and it is recorded as a
  documented exception in Phase 5.
- **Metering placement.** The budget is checked after validation and before the
  insert, so a rejected request costs no quota while a loop cannot outrun the
  limit. The fingerprint is the first 16 hex characters of the token digest — it
  separates callers without storing anything that could authenticate a request.
- **`reject` is a function declaration**, not an arrow const, so the compiler
  treats a call as non-returning and narrows `Doc | null` after a guard. An arrow
  const with an explicit `never` return did not narrow, and `tsc` failed.
- **Slug fallback.** A title of only punctuation yields an empty slug and a 400
  rather than a post at an unreachable URL.
- **Phase 4 will extend** `convex/contentApi.ts` and `convex/http.ts` with partial
  update and the publish/unpublish transitions; this phase deliberately stops at
  create and read.
