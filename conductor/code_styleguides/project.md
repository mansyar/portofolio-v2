# Project Code Style — Portfolio v2

Project-specific overlay on top of `general.md` and `typescript.md`. Where this file and
a library guide disagree, **this file wins**. Where this file is silent, the library
guides apply.

The repository also carries `.agent/rules/project-rules.md` and `.agent/workflows/`.
Those remain valid and describe the same conventions; this file is the authoritative
version for Conductor work, and the two should not drift. If they ever conflict, treat
this file as correct and raise the drift.

## Stack-specific rules

### Type safety

- **`any` is a build error**, not a warning - Biome's `noExplicitAny` is set to `error`.
  Use `unknown` plus a type guard.
- **Validators are split by boundary:** Convex validators (`v.*`) on the backend, Zod on
  client-side input. Never validate the same input twice with two different libraries.
- **Explicit return types on async functions.** Inferred returns on a `query`/`mutation`
  handler are fine; `async` helpers in `src/lib/` and `convex/lib/` are not.
- **No non-null assertions (`!`) or `as` casts** without a comment explaining why the
  compiler cannot know. The library guide says this; it is enforced here.

### Convex backend

- **Every mutating function calls `await requireAdmin(ctx)` as its first statement**,
  before validation and before any read. A mutation that skips it is a security bug, not
  a style issue.
- **Queries are index-driven.** Use `.withIndex(...)` where an index exists; a full
  `.filter()` scan on a growing table is a performance bug waiting to happen.
- **`convex/_generated/` is committed and never hand-edited.** It is regenerated by
  `npx convex dev --once`.
- **Cross-file server calls use `internal.*`**, not `api.*`, unless the function is
  intentionally public.

### React and TanStack

- **Named exports only.** No default exports for components.
- **Components under ~200 lines.** Extract past that.
- **Co-locate CSS:** `button.tsx` + `button.css`.
- **Three component directories only:** `ui/` (primitives), `features/` (domain),
  `layout/` (structural). Do not add a fourth.
- **SSR data through `convexQuery` + `useSuspenseQuery`**; mutations through
  `useMutation` from `convex/react`. Do not add a second data layer (no manual
  `useEffect` fetching, no SWR).
- **No manual refetching.** Convex reactivity invalidates queries; a `refetch()` call is
  almost always a symptom of a missing reactive dependency.
- **Imports are ordered** imports → types → component, matching the existing files.

### Styling

- **Tokens before literals.** Any color, font size, weight, or spacing value must come
  from `variables.css` as a CSS custom property. A raw hex in a component stylesheet is a
  review failure.
- **Tailwind is the styling tool**, and tokens feed it. Reach for a co-located `.css`
  file only for keyframes, terminal chrome (window title bars, prompts), or selectors
  Tailwind cannot express cleanly.
- **Dark mode first.** Both themes must pass contrast independently; see
  `product-guidelines.md`.

### Routing and file layout

- Routes live in `src/routes/` using TanStack file-based conventions: `index.tsx`,
  `$slug.tsx`, `_layout.tsx`, and `route.lazy.tsx` variants.
- `src/routeTree.gen.ts` is **generated** - never edit it, never lint-fix it, and it is
  excluded from Biome and from coverage.
- **Admin code does not leak into public bundles.** A component used only by
  `src/routes/admin/**` must not be imported from a public route.
- Hooks go in `src/hooks/`, pure helpers in `src/lib/`. A helper used by exactly one
  component may stay beside it.

### Security

- **Never commit secrets.** `.env.local` is gitignored; only `VITE_`-prefixed values are
  inlined into the client bundle.
- **All `/admin/*` routes are guarded** by a session check, and the guard is server-side
  where the route supports it.
- **Rich text is sanitized** through `isomorphic-dompurify` before rendering. Never add
  a `dangerouslySetInnerHTML` path that bypasses it.
- **Uploads validate type and size** before reaching Convex storage.

### Accessibility (enforced, not aspirational)

The gaps in `product-guidelines.md` are debt to pay down, but **new code must not add to
them**:

- Every new interactive element is keyboard reachable and has a visible focus state. If
  the shared primitive lacks one, fix the primitive.
- Every new animation is wrapped in a `prefers-reduced-motion` guard.
- Every icon-only control has an `aria-label`.
- Semantic elements over `div` + `role`; one `<h1>` per page; images carry `alt`.

## Commands

```bash
pnpm type-check     # tsc --noEmit
pnpm lint           # biome check .
pnpm format         # biome check --write .
pnpm format:check   # biome check . (no writes)
pnpm test           # vitest run
pnpm test:coverage  # vitest run --coverage
pnpm build          # vite build
```

Biome is the single formatter and linter. There is no ESLint or Prettier - do not add
`eslint-disable` or `prettier-ignore` comments. Use `// biome-ignore lint/<group>/<rule>: <reason>`
when a finding is a genuine false positive, and always give the reason.

## Comments

- **Comments explain why.** The library guide says this; it is the most-violated rule in
  practice. A comment that restates the code should be deleted.
- **No commented-out code.** Git remembers it.
- **`// TODO(name): reason`** is the only acceptable TODO form, and it names the owner
  and the condition for removal.

## What not to do

| Don't | Do |
| --- | --- |
| `as SomeType` to silence the compiler | Narrow with a type guard |
| `.filter(q => ...)` on an indexed field | `.withIndex(...)` |
| A raw `#e95420` in a stylesheet | `var(--color-ubuntu-orange)` |
| A new `useEffect` fetch | `useSuspenseQuery(convexQuery(...))` |
| A fourth component directory | Extend `ui/`, `features/`, or `layout/` |
| `dangerouslySetInnerHTML` without sanitize | `isomorphic-dompurify` |
| Editing `routeTree.gen.ts` or `_generated/` | Regenerate with the tool |
| A default export | A named export |
